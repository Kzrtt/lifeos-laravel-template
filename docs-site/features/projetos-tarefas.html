Projetos e Tarefas

Projetos agrupam o trabalho; tarefas sempre vivem dentro de um projeto e andam num kanban.

✅ implementadokanbanprojetostarefas

O problema

Acompanhar o que está em andamento em cada frente da vida, com um olhar rápido no hub e o detalhe numa página própria.

As regras

  1. Um projeto tem nome, emoji opcional, status (Não Iniciado, Em Progresso, Feito, Pausado) e tags (Pessoal, Profissional, Acadêmico, Configuração).
  2. Toda tarefa pertence a exatamente um projeto — criar sem projeto é recusado (missing_projeto_id).
  3. Tarefa tem status (Não Iniciado, Em Andamento, Feito), tipos, data de entrega opcional e descrição em markdown.
  4. Não se apaga projeto com tarefa: a exclusão responde has_tarefas. É preciso mover ou excluir as tarefas antes.
  5. Só projetos Em Progresso aparecem como opção ao criar/mover uma tarefa; ao editar, o projeto atual continua na lista mesmo que tenha mudado de status.
  6. No hub (desktop) dá para arrastar uma tarefa entre colunas do mini-kanban: grava só o novo status.
  7. Status e tipos vêm dos vocabulários; as visões salvas filtram por projeto, tipo e status.

A FK lifeos_tarefas.projeto_prj_id é restrict. A tarefa sem filtro de projeto devolve todas — é o que o hub usa para o mini-kanban e as estatísticas.
