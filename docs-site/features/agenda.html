Agenda (Eventos)

O calendário do hub: eventos de um dia ou de vários, opcionalmente ligados a um projeto.

✅ implementadocalendárioeventos

O problema

Ver o mês de relance — viagens, congressos, compromissos — e, se quiser, trocar a mesma grade para as entregas das tarefas.

As regras

  1. Um evento tem nome, data, data final opcional (viagem, congresso…), tipo (vocabulário evento_tipo, com cor) e projeto opcional.
  2. A data final, quando existe, não pode ser anterior à inicial — validado com a data efetiva (num patch só com uma das duas, a outra vem da linha atual).
  3. Evento de vários dias aparece em todo dia do intervalo no mini-calendário.
  4. A busca por período devolve os eventos que se sobrepõem ao intervalo, não só os que começam dentro dele; intervalo inválido é recusado (invalid_range).
  5. Excluir um projeto desvincula o evento (ele continua existindo, sem projeto).
  6. O calendário do hub alterna entre Eventos e Tarefas (entregas): só muda o que é exibido; criar evento é pelo hub, criar tarefa é pela página de tarefas.
  7. O hub busca uma janela de meses e completa os que faltarem ao navegar; a janela é recalculada em relação a “hoje” a cada visita.
