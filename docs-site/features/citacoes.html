Contexto · módulo citacoes

Citações

Uma frase sorteada a cada abertura do hub, com a lista completa atrás de um clique.

✅ implementadobannersorteio

O problema

Uma tabela de citações que funciona diferente das outras listas: a área não mostra a lista, mostra uma citação.

As regras

  1. Uma citação é um texto (até 2000 caracteres) e um autor (até 200).
  2. O sorteio roda a cada abertura do hub e a cada ↻; com mais de uma citação, nunca repete a que já está na tela.
  3. Editar atualiza o texto no lugar, sem re-sortear; excluir a que está no banner sorteia outra.
  4. *trecho* no texto vira destaque na cor de acento.
  5. Citações são exceção ao cache “eterno até ↻”: o hub as busca a cada abertura, porque também chegam pelo MCP.
  6. Sem nenhuma citação, o banner vira um convite e o clique abre direto o formulário.
