Manifestações

Intenções e metas com banner, status e tags, com modo foco no hub.

✅ implementadometasbanner

O problema

Manter à vista aquilo que se quer trazer para a vida — separado das tarefas do dia a dia.

As regras

  1. Uma manifestação tem nome, status (Não Iniciado, Em Progresso, Feito), tags (Vida, Financeiro, Carreira, Saúde, Lazer) e descrição opcional.
  2. O banner é opcional: sem imagem, o hub usa um banner padrão estilizado.
  3. O banner enviado é gravado no servidor depois de a manifestação existir; imagem grande demais é recusada (banner_too_large, limite de ~4,5 MB de arquivo).
  4. Falha ao salvar a imagem não desfaz a manifestação já criada.
  5. O modo foco do hub esconde as demais seções (inclusive o banner de citação) para olhar só as manifestações.
