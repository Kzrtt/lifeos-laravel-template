Backup

Um zip com todos os dados do LifeOS, gerado a partir do hub.

✅ implementadobackup.sqlzip

O problema

Ter uma cópia de tudo que não dependa do servidor estar de pé.

As regras

  1. O backup devolve um arquivo .sql por tabela do tenant, mais a contagem de linhas de cada uma.
  2. Credenciais entram por padrão; quem não quiser pede sem elas. Só quem tem a senha mestre gera backup.
  3. O .zip é montado no navegador, sem biblioteca (formato ZIP mínimo, deflate nativo), a partir do texto que o servidor devolve.
  4. Além do backup sob demanda, há o comando lifeos:dump-banco (dump do Postgres, mantém os N mais recentes, 14 por padrão) para a rotina do servidor.
  5. O caminho de volta: lifeos:importar-supabase importa uma instância do LifeOS original.
