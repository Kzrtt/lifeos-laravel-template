Banco de dados

Modelo de Dados (DER)

PostgreSQL 16 próprio, acessado só por Eloquent. Tudo que tem dono carrega entity_ent_id (o tenant); toda coluna leva o prefixo de 3 letras da tabela e a chave primária é UUID.

✅ implementado

Relações principais

Linha cheia = chave estrangeira no banco. Linha pontilhada = referência lógica: o módulo dono do dado não cria FK para a tabela de outro módulo (fronteira de módulo é sagrada); a limpeza, quando o projeto some, é feita por evento/ação. Todas as tabelas de domínio também apontam para entities — omitido do desenho para não poluir.

Convenções

  1. Prefixo de 3 letras em toda coluna (not_name, tar_status…); FKs seguem {tabela_singular}_{pk}.
  2. UUID como chave primária de tudo.
  3. SoftDeletes com <prefixo>_deleted_at nas tabelas transacionais; unicidade (ex.: nome de renúncia, título de memória) vale só entre registros não apagados, via índice parcial.
  4. Colunas <prefixo>_created_at / _updated_at existem em todas e não são repetidas abaixo.
  5. Listas (tipo, tags) são text[] do PostgreSQL — por isso o banco de teste também é PostgreSQL.
  6. Toda mutação cai em audit_logs (append-only) por Observer; colunas sensíveis ficam fora do diff.
