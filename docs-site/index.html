Planejado
◇ Decisões já tomadas, ainda sem código — têm a mesma autoridade de uma regra implementada:
  • Notas — Resolução de vínculos nota ↔ nota (menções viram link para a nota local).
  • Notas — Gráficos e estatísticas dentro de notas.html (hoje só o hub mostra a distribuição por tipo).
  • Manifestações — Editar e excluir manifestações — hoje só existem consulta e criação.
  • Manifestações — Tela para editar a descrição (a coluna existe, ainda sem UI).
  • Renúncias — Card ou resumo de renúncias no hub — decisão explícita: só no menu.
Como ler: cada página de módulo tem duas visões — Regra de negócio (prosa, sem nome de classe) e Código (tabelas, rotas, Actions). A escolha é lembrada entre páginas. Se uma página divergir do código, é bug de documentação.
